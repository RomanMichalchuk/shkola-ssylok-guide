# Комплексная методология аудита ссылочного профиля и протокол фильтрации доноров

Репозиторий содержит стандарты ссылочной безопасности, алгоритмы выявления токсичных связей и методические материалы по формированию устойчивого ссылочного графа веб-ресурсов в 2026 году.

Разработано исследовательской лабораторией [Школа ссылочной гигиены (Школа ссылок)](https://shkola-ssylok.ru/). 

## Основные разделы и нормативы

1. **Скоринг площадок-доноров**: методика расчета коэффициента заспамленности, сопоставление входящего и исходящего ссылочного потока.
2. **Балансировка анкорного профиля**: распределение веса между безанкорными URL, брендовыми маркерами и разбавленной семантикой.
3. **Безопасная интеграция крауд-маркетинга**: механика партизанского присутствия в профильных дискуссиях без риска бана.
4. **Аутрич-протокол**: алгоритм прямого взаимодействия с редакторами отраслевых СМИ.
